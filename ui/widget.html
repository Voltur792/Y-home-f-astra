Подключение к Яндексу

Как получить OAuth-токен:

  1. Откройте создание приложения и выберите тип «Для доступа к API или отладки».
  2. В разделе «Доступы» найдите Умный дом Яндекса и добавьте права iot:view и iot:control.
  3. Нажмите «Создать приложение» и скопируйте его ClientID.
  4. Откройте ссылку, подставив свой ClientID:
    https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENTID
  5. После авторизации Яндекс покажет токен — скопируйте его (начинается с y0__) и вставьте ниже.
